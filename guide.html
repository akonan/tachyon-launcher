Using Tachyon

Home is a clock and a few names. Everything else is one search bar. This page covers installing it, using it, and changing it through the config file.

This is a research preview built for one person's phone. Home starts with the author's pinned apps and two of the swipes open the author's apps. The first five minutes shows how to make it yours.

Install

  1. Download the research preview APK (399 KB) on the phone. It needs Android 15 or later.
  2. Open the file. Android asks you to allow your browser or file manager to install apps, and warns that the app is from an unknown source. It is debug-signed and in no store, so both warnings are expected.
  3. Try it first. Open "Tachyon" from your app list. Nothing changes on the phone until the next step.
  4. Make it the home app. Settings → Apps → Default apps → Home app → Tachyon. App shortcuts ("Firefox: New tab") appear in search only while Tachyon is the home app; Android allows only the home app to read them.

To go back, choose your old launcher in the same Home app setting. Uninstalling Tachyon also deletes its config and secrets.

On a Boox, switch off "Freeze new apps" before installing, or Boox disables the app on arrival. Then exclude Tachyon from app freezing so it is not killed in the background.

The first five minutes

  1. Clear the author's pins. Hold a name on Home and choose "Unpin from home". Pins for apps you do not have are drawn in grey.
  2. Pin your own. Swipe up, type an app's name, hold the row (or tap Actions) and choose "Pin to home".
  3. Pick a theme. Type > theme and choose Light, Dark or System.
  4. Fix the side swipes. Swipe left and swipe right open two of the author's apps. Type > edit config and change gestures; see the config file.
  5. Drop "Ask agent". When nothing matches a search, the first row offered sends your text to a web address you have not set up. Until you set one up, put web search first: in the config, set "fallbacks": ["action:web-search"] inside search.

Home shows the date, a large clock, a battery and Wi-Fi line, and your pins. There is no wallpaper, no icons and no status bar.

From inside any app, pressing the home button twice is "search". Every gesture can be changed, and double tap and taps on the clock, date and battery line can be given actions too.

Search

One bar searches apps, app shortcuts, system settings, commands, modes and your own actions. The best match sits nearest the bar in an inverted row; Enter runs it.

  • Ranking. Exact match, then prefix, word start, acronym (gm finds Google Maps), substring, then fuzzy: your letters in order, with gaps. Ties go to what you use most and most recently.
  • Auto-launch. When at least two letters match exactly one app, it opens at once. You do not press Enter. It never auto-runs a shortcut, command, setting or action.
  • It remembers your pick. Whatever you open for a query comes first the next time you type exactly that query.
  • Typos. When four or more letters match nothing, names one typing mistake away are offered. A near miss is never auto-launched.
  • Empty bar. Shows your recent apps.
  • Nothing found. Fallback rows appear ("Ask agent: …", "Web search: …") so any text plus Enter does something.
  • Dictation. The bar is a normal text field to Android, so voice typing and TalkBack work in it.

Query prefixes: > lists commands, = forces the calculator, mode then Enter opens Modes, dash then Enter opens the Dashboard.

Keywords

A keyword takes the rest of the line as its argument. A preview row shows what will run before you press Enter.

These are the bundled ones. You add your own in the config: any URL, app link, Android intent or web request with {query} in it.

Calculator

Type an expression and the result appears as you type. Enter copies it.

  • Operators: + - * / ^ % ! and parentheses.
  • Functions such as sqrt, ln, round(x, n) and hypot.
  • Constants: pi, e, tau, phi.
  • Start with = when the text could also be a search, as in =sqrt(2).

Actions and pins

Hold any row or pin, tap the Actions button, or hold Enter for half a second. The sheet offers:

  • Open, and the app's own shortcuts (new tab, a chat, a channel).
  • Pin to home or Unpin from home.
  • Hide from search or show again.
  • App info and Uninstall.

Pin an action inside an app

Pins are not only apps. Search for a shortcut such as "Slack: #dailies", "Firefox: New tab" or a chat, open Actions on that row and choose "Pin to home". One tap on Home then goes straight there. Your own actions and commands can be pinned the same way.

Home draws as many pins as fit the screen. A pin beyond that is saved but not shown.

Theme

Type > theme. Light is black on white. Dark is white on true black. System follows the phone's dark theme setting. There are no other colours.

On a phone with a notch or a punch-hole camera, content starts below it. Nothing to set.

Modes and dashboard

Modes (mode, then Enter) swap Home for a purpose: a mode has its own pins and gestures, and applies the device settings Android lets an app change, such as notification silence and, on e-ink, refresh mode and front light. A setting it may not change (Wi-Fi, for one) is named once in the status line. The bundled modes are examples from the author's phone; write your own in the config.

Dashboard (dash, then Enter) shows a countdown, three numbers and a line to remember. In this preview the content is whatever you type into the config; it does not fetch anything yet.

Hardware keys

  • Volume up and down move the selection, in lists and through the pins on Home.
  • Enter, D-pad centre or a device's smart key run the selection.
  • Hold one of those for half a second to open Actions.

Any key can be bound. Run > key tester, press the key, and use the code it shows: "code:131": "builtin:openDashboard".

The config file

Everything above is data in one JSON file. Type > edit config: Tachyon writes a file with your current settings and opens it in a text editor app. Save, come back, and type > reload config.

From a computer, the file is at /sdcard/Android/data/dev.palma.launcher/files/config.json:

adb pull /sdcard/Android/data/dev.palma.launcher/files/config.json
adb push config.json /sdcard/Android/data/dev.palma.launcher/files/config.json
  • Your file overrides the built-in defaults section by section. A top-level section you write (home, gestures, actions, …) replaces the built-in one whole. A section you leave out keeps its defaults.
  • A mistake cannot break the launcher. A bad section falls back to the defaults, and a "Config: n errors" row under > says what is wrong and where.
  • Pinning, hiding and the theme picker write to this same file, so you can mix editing by hand and by tapping.

Writing an action

An action is a short string or an object. A list of actions runs in order.

WriteIt does
"app:Firefox"Opens an app, by name or package
"url:https://…", or any scheme://…Opens a link, including app links such as obsidian://
"builtin:openSearch"Runs a built-in command
"mode:evening"Switches mode
"action:web-search"Runs one of your actions by id
"settings:display"Opens a system settings page
"none"Nothing; use it to switch a gesture off
{ "type": "intent", … }Sends an Android intent
{ "type": "http", … }Makes a web request

Text in an action can use {query}, {clipboard}, {date} and {secret:NAME}. Add a filter after a colon: {query:url} for links, {query:json} inside JSON, and :trim, :upper, :lower.

Your own keywords

"actions": [
  { "id": "web-search", "title": "Web search", "keyword": "g",
    "action": "url:https://duckduckgo.com/?q={query:url}" },
  { "id": "wiki", "title": "Wikipedia", "keyword": "w",
    "action": "url:https://en.wikipedia.org/wiki/Special:Search?search={query:url}" },
  { "id": "daily", "title": "Daily note", "aliases": ["today"],
    "action": "obsidian://daily" },
  { "id": "share", "title": "Share text", "keyword": "share",
    "action": { "type": "intent", "action": "android.intent.action.SEND",
                "mimeType": "text/plain",
                "extras": { "android.intent.extra.TEXT": "{query}" } } }
]

A keyword takes an argument (w tachyon). aliases are extra names the action is found by. Because actions replaces the built-in list whole, keep the bundled ones you still want in your file; the file that > edit config creates already contains them.

Search behaviour

"search": {
  "autoLaunch": true,
  "autoLaunchMinChars": 2,
  "learn": true,
  "maxResults": 8,
  "recentCount": 6,
  "fallbacks": ["action:web-search"]
}

If auto-launch opens apps you did not mean, raise autoLaunchMinChars to 3 or set autoLaunch to false.

Webhooks and secrets

An http action sends text to a web address of yours: a home automation hook, a notes inbox, an AI agent. Tokens and private addresses do not go in the config. Store them on the phone by typing in the search bar:

secret set agent_url https://example.com/v1/run
secret set agent_token YOUR_TOKEN

The bar is masked while you type a secret. secret list shows the names, never the values, and secret rm NAME deletes one. Secrets stay on the device, outside backups, and are never shown or logged. The config refers to them by name:

{ "id": "agent", "title": "Ask agent", "keyword": "agent",
  "action": { "type": "http", "method": "POST",
              "url": "{secret:agent_url}",
              "headers": { "Authorization": "Bearer {secret:agent_token}" },
              "contentType": "application/json",
              "body": "{\"prompt\": \"{query:json}\"}",
              "successMessage": "Sent", "timeoutMs": 15000 } }

The bundled "Ask agent" action already reads agent_url and agent_token, so setting those two secrets is enough to make it work. Addresses must be https://; plain http:// is allowed only to localhost and Tailscale names (*.ts.net). This is the only thing Tachyon uses the network for.

E-ink and Boox

Tachyon never animates, on any screen. On Onyx Boox devices it detects the e-ink panel by itself. On another e-ink device, say so in the config:

"eink": { "panel": "eink", "coalesceMs": 0, "launchTapGuardMs": 500 }
  • panel: auto, eink or lcd.
  • coalesceMs: while you type fast, draw at most one frame per this many milliseconds. Try 150 to 250 on a slow panel.
  • launchTapGuardMs: taps are ignored this long after an app is opened, so a second tap on a slow panel cannot land in the wrong place.

Full refresh clears ghosting. Refresh mode and Front light use Boox controls and have had little testing. A lock-screen dashboard for the Boox sleep screen exists but is off by default and experimental ("lockscreen": { "enabled": true }, then > update lock screen; > restore boox screensaver undoes it).

Known limits

  • Android 15 or later only.
  • The defaults are one person's. Pins, side swipes, modes and the dashboard text all need replacing. A neutral first run is on the roadmap.
  • You will reinstall once. The package name changes before the real release, and the config path with it. Keep a copy of your config.json.
  • No work-profile shortcuts as pins, and settings rows and built-in commands cannot be pinned yet.
  • No widgets, icons, folders or wallpaper. That is the design, not a gap.
  • Tested on two phones. If something breaks on yours, that is useful to know.
