# Tachyon

A text-only Android launcher, out as a research preview.

This repository holds the website: https://akonan.github.io/tachyon-launcher/

The launcher's source code and the benchmark behind the site's numbers are not here yet.
Both will be published as open source.

The research preview APK is in `download/`. It is debug-signed, needs Android 15 or later,
and its package name will change before the real release.
